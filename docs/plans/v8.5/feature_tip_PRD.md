# v8.5 重试开关首次引导气泡 PRD

> 状态：🟢 已实施
> 关联：`docs/plans/v7.7/fast_retry_PRD.md`、`docs/plans/v8.3/long_task_mode_PRD.md`、`docs/plans/v8.4/fast_retry_chain_PRD.md`
> 用户诉求（2026-11-19）：「给初次打开的用户一个快速重试和长任务模式开关的气泡指引。」

---

## 一、问题

「快速重试」与「长任务模式」两个开关并排出现，但一个是**加快节奏**、一个是**延长总预算**，
新手很容易看成一回事；且两者都只在任务排队时才有意义，用户往往在紧张等结果时才发现它们。

## 二、方案

进度页重试面板首次出现时，弹一张**两步引导卡片**：

1. **快速重试**：上游排队满时按设定频率连打（例：每分钟 30 次、持续 3 分钟）；
   一轮结束后回常规节奏，等设定间隔再自动开下一轮。
2. **长任务模式**：把「重试次数上限」换成「累计等待时长」（默认 60 分钟），
   适合长视频排队；频率不变，默认值可在设置页改。

交互：

- 卡片内「1/2 · 下一步」→ 第二步 →「知道了」；
- 右上角 ✕ 或「跳过」直接关闭；
- 关闭后写 `localStorage['wb_tip_retry_modes_seen'] = '1'`，**跨任务只弹一次**；
- 隐私模式读不到 localStorage 时仍展示一次，只是不写标记（不阻断使用）。

## 三、触发时机（重要）

不是「打开网站就弹」，而是**重试面板真正出现时**才弹：

- 面板可见 = `fast_retry.available`（已连续 2 次队列满）**或** 长任务状态已就绪且是视频任务；
- 长任务状态是 `BaseTaskState` 的字段，视频任务一进进度页就下发，因此多数用户
  **第一条视频任务进入进度页时**即可看到引导；
- 图片任务、任务已失败（面板隐藏）时不会弹。

## 五、验收

| 编号 | 场景 | 预期 |
|---|---|---|
| FT1 | 首次进入带面板的进度页 | 显示第 1/2 步，内容为「快速重试」 |
| FT2 | 点「下一步」 | 切到第 2/2 步，按钮变「知道了」 |
| FT3 | 点「知道了」/「跳过」/ ✕ | 关闭并写标记，之后任何任务都不再弹 |
| FT4 | 刷新页面 | 不再弹（localStorage 生效） |
| FT5 | 图片任务 / 任务失败 | 不弹 |
| FT6 | 隐私模式（localStorage 不可用） | 仍展示一次，不报错 |
