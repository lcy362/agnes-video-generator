## 调研方法提示

评估一个待调研点是否转入可执行清单，建议对照：

1. **现状盘点**：该能力当前实现到什么程度（直接读代码，不臆测）。
2. **真实增量**：相对现状能提升什么、提升多少（区分"功能空白"与"边际优化"）。
3. **代价**：涉及文件数、回归面、对免费模型限速/质量的依赖。
4. **硬限制**：模型能力天花板（如视频模型参考图身份保持力、TTS 多音色口型）。
