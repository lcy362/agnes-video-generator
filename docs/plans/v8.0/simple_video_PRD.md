# 简单视频模式优化 PRD（v8.0 方向二）

> 状态：🟢 已实施（P0 + P1）
> 关联：`docs/plans/v8.0/README.md`、`docs/plans/v8.0/system_design.md`、`docs/plans/v8.0/implementation_plan.md`
> 接口依据：Agnes 官方 wiki 文档（`agnes-video-25` / `agnes-video-25-flash`，2026 版）＋
> `docs/dev/agnes_video_upstream_behavior.md`（实测）

## 一、背景

简单视频是使用频率最高的入口，但「无特殊需求时一键生成」并未真正做到：

1. **默认产物方向错误**：前端默认画幅 `9:16`，而 2.5-flash 竖屏存在上游画面躺倒缺陷，
   竖屏校正开关默认关闭。用户只输入提示词点生成，拿到的第一条片子方向就是坏的。
2. **界面不像一键**：主区有模型选择、能力卡片、模式/时长/比例/清晰度 4 个下拉；
   且默认 `mode='t2v'` 不在 2.5 的 `text/reference/keyframe` 选项里，生成模式下拉首次渲染为空白。
3. **默认值三套并存**：前端 `reactive`、后端 `Form(...)`、`BaseTaskState` 各写一份；
   兜底时长含 `15/18/20`（后端白名单 `4–12`），选中即 422；草稿跨模型恢复无白名单校验。
4. **接口新能力未对齐**：官方 2.5 已支持原生首尾帧、≤5/≤8 张参考图、≤3 段参考音频，
   产品仍停留在「单参考图 + 尾帧塞进 images」；付费档 `960P` 在上游并不存在（必 400）。
5. **付费档无防误选**：模型下拉里免费/付费混排，免费用户可能直接选中付费档并产生费用。

## 二、目标与非目标

### 目标

- **一键可用**：只输入提示词、点一次生成，得到一条方向正确、免费、可用的 5 秒横屏视频。
- **预设单一来源**：所有默认值由后端 `SIMPLE_DEFAULT_PRESET` 定义并经 `/api/models` 下发。
- **前端对齐接口**：首尾帧 / 多图 / 参考音频全部可从 UI 完成，含 `<Picture N>` / `<Audio N>` 引导。
- **付费档不误选**：免费档排前、逐项标注、选中付费档必须二次确认。
- **默认进入简单视频**，并记住用户上次选择的类型。

### 非目标

- 不重写流水线主流程，不改多场景模板方法。
- 不改 API 路径与既有字段语义，不做 UI 整体重构（v8.0 方向一另行）。
- 本期不暴露参考视频 `videos[]`、不做本地音频文件上传（仅公开 URL）。
- 不默认开启竖屏旋转校正（会改产物，另行评估）。

## 三、功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-1 | 一键预设 | 默认 `2.5-flash` / 文生视频 / 5s / 16:9 / 720P；仅 `prompt` 必填 |
| FR-2 | 默认类型与记忆 | 首次进入默认 `simple`；切换类型写入 localStorage，下次沿用 |
| FR-3 | 表单分层 | 主区只留提示词 + 预设摘要 + 生成按钮；其余收进「修改设置」 |
| FR-4 | 原生首尾帧 | `keyframe` 模式上传首帧/尾帧（至少 1 张），走 `first_frame`/`last_frame` |
| FR-5 | 多图参考 | `reference` 模式多图上传（Flash ≤5 / 2.5 ≤8），可逐张移除 |
| FR-6 | 参考音频 | `reference` 模式填 0–3 个公开 http(s) URL，支持 `<Audio 1>` |
| FR-7 | 付费档防护 | 下拉按免费优先排序 + `免费/付费` 标签 + 醒目标识 + 生成前二次确认 |
| FR-8 | 模式素材校验 | reference 至少 1 图/音频；keyframe 至少 1 帧；keyframe 与 images/audios 互斥 |
| FR-9 | 预设恢复 | 一键「恢复默认」回到免费档与官方推荐值 |
| FR-10 | 文档同步 | API / 使用说明 / FAQ / 上游行为文档与实现一致 |

## 四、验收标准

1. 清空 localStorage 后打开创建页：默认停在简单视频，画幅 16:9，生成模式显示「文生视频」（非空白）。
2. 仅输入提示词点生成：`ok:true`，任务参数为 `5s / 1280×720 / 720P / flash`。
3. `curl -F "prompt=..."` 只带 prompt 也可创建成功。
4. 选 `reference` 不上传素材：前端即时提示，不发起请求；直调 API 混传 keyframe + images 返回 422。
5. 付费档在下拉中标注 `付费`，选中后出现醒目提示并在生成前要求确认；「恢复默认」回到免费档。
6. 历史任务（缺 `reference_images` / `first_frame_image` 等新字段）可正常反序列化与续传。
7. 22 语言文案完整；前端构建通过；`tests/` 全绿。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 改默认画幅与老草稿冲突 | 视频草稿只恢复提示词，设置项一律以预设为准 |
| keyframe 仍存在 704×704 缺陷 | 默认原生 keyframe，保留 `AGNES_KEYFRAME_NATIVE=0` 一键回退；**2026-11-12 已复验：方形输出根因是本项目托管链路把首尾帧方化（`1024x1024`），已修复，见 `docs/dev/agnes_video_upstream_behavior.md` §9.5.3** |
| 参考音频需公开 URL | UI 明确提示；本地音频上传待确认上游通用上传通道后再做 |
| 付费档误选 | 三重防护：排序 + 标注 + 二次确认；默认与恢复默认均为免费档 |
