# ✨ 核心功能

## 🎬 多种创作模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **单镜头短片**（原「简单视频」） | 一条 prompt → 一条 4–12 秒 AI 视频。参数全部可调（模型、生成模式、时长、画幅、seed、负向提示词），支持文生视频、图生视频、首尾帧、参考图与参考音频。一键预设为免费 `agnes-video-2.5-flash` / 5 秒 / 16:9 / 720P。 | 快速生成免费 AI 短视频 |
| **多镜头故事**（原「创意长视频」） | AI 全流程：创意 → 故事 → 脚本 → 角色参考图 → 1–30 个镜头 → 旁白配音 → 字幕 → 拼接成片。 | 故事短片、创意视频 |
| **稿件长视频** | 粘贴长文/稿件 → 按朗读时长自动拆段 → 逐段 AI 视频 → 统一 TTS 旁白 + 字幕叠加 → 拼接成片。 | 解说视频、课程内容、Vlog |
| **数字人口播** | AI 生成主播形象（或上传自定义形象）→ 口播片段 → TTS 配音 → 字幕 → 循环拼接；支持 `post_stitch` 后配音或模型自带口型音频。 | 虚拟主播、产品口播、新闻播报 |
| **诗词视频** | 古诗 → 逐句拆场景（原诗句作旁白）→ 逐句 t2v + 朗诵 + 定时字幕 → 拼接成片。 | 古风短片、意境动画 |
| **简单图片** | 单次调用 Agnes Image API 完成文生图 / 图生图，支持参考图。 | 封面图、角色板、风格板 |

## 🆓 完全免费的 AI 模型链

所有核心 AI 能力**全部免费**，无试用期、无水印、无 token 限制：

| 能力 | 模型 | 费用 |
|------|------|------|
| 文本 / 脚本生成 | `agnes-3.0-flash` | 免费 |
| 图片生成 | `agnes-image-2.5-flash` | 免费 |
| 视频生成 | `agnes-video-2.5-flash` | 免费 |
| 语音旁白（TTS） | Edge TTS（微软） | 免费，无需额外 API Key |

所有 AI API 调用共享令牌桶限速（共享桶默认 20 × Key 数 × 0.8 次/分钟，另有视频提交独立桶），配额随 Key 数线性放大，含自动重试和指数退避，确保稳定可用。

## 🎙️ AI 旁白配音与智能字幕

多镜头故事和稿件视频均支持：

- **免费 TTS 旁白**：基于微软 Edge TTS，提供按 22 种界面语言分组的动态音色目录（支持试听与跨语言兼容性校验），语速可调
- **词级细粒度字幕**：基于 TTS 词级时间戳生成 SRT 字幕，每 2-3 秒一条，音画精准同步
- **多行自动换行**：长字幕文本智能拆分为两行，优先在标点处断行，避免溢出屏幕
- **字幕样式全自定义**：字体、颜色、字号、位置（顶部/底部）、描边、半透明背景
- **音频-视频同步策略**：先拼接所有视频片段，再整体叠加合并音频和字幕，避免逐段叠加的累积误差。TTS 自动放大 1.5 倍音量补偿默认低音量

## 🎨 灵活的创作控制

- **自定义参考图** — 上传角色或场景参考图，保持多场景外观一致性
- **自定义尾帧** — 为每个场景指定尾帧图片，精确控制视频画面过渡
- **图生图尾帧** — 基于参考图用 img2img 自动生成场景尾帧
- **三种视频串联模式** — `keyframes`（首尾帧插值过渡，推荐）/ `ti2vid`（场景间过渡帧）/ `none`（独立场景）
- **按比例输出** — 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16（默认 16:9；2.5 Flash 固定 720P）
- **单镜头短片一键生成** — 只填提示词即可：免费 2.5 Flash / 5s / 16:9 / 720P 预设；付费档明确标注并需二次确认
- **灵活时长** — 自定义场景时长
- **稿件智能拆段** — 按句号/问号/感叹号拆分，基于朗读速度（约 4 字/秒）贪心合并为 5-12 秒段落，长句不拆分、短句自动向前合并

## 🆕 近期新增能力（v7.6–v8.2）

- **多参考图**（v8.1）：Flash 最多 5 张、2.5 最多 8 张；人物板、风格板、衔接静帧与逐段内容图统一合并去重，并可在 `references` 检查点逐场景补图。
- **原生首尾帧与参考音频**：2.5 系列接口支持 `first_frame` / `last_frame`、`images[]` 与公开 URL 的 `audios[]`。
- **手动模式与外部素材**：可在检查点暂停并编辑产物，也可导入外部生成的片段（即梦工作流，试验中），用 `concat_videos_keep_audio` 保留原音轨合成。
- **长任务模式**（v8.2）：用累计忙轨等待时长（默认 60 分钟，5–480 可调）替代固定重试次数；**快速重试**支持自动接力下一轮；确定不可重试的上游错误会分类并快速失败。
- **AI Agent 技能**：一个独立 skill 完成装服务、出片、交付文件、排查失败，并在你同意后修真实缺陷、提交 PR。

## 🔧 生产级可靠性

- **断点续传** — 任务中断后自动从断点恢复，每个步骤完成后落盘状态，不重复调用 API

## 🎬 三种 AI 视频串联模式

| 模式 | 原理 | 适用场景 |
|------|------|---------|
| **keyframes** | 每场景指定首帧+末帧，服务端自动插值过渡 | 追求平滑过渡（推荐） |
| **ti2vid** | 上一场景末帧 → img2img 过渡图 → 下一场景首帧 | 需要场景间视觉连续性 |
| **none** | 所有场景共用同一参考图，互不依赖 | 快速出片，场景独立 |
